How to Set TWAP Parts and Timing for a Token Sale

Choose a TWAP part count and interval by checking price impact per part, then balance pool recovery time against the network cost of each execution.

By Crypto Readout EditorialNov 24, 2026 · 22:40 UTC4 min read#58cb66

For a cowswap TWAP sale, choose the fewest parts that keep each part’s estimated price impact below about 0.5%, then space them long enough for the pool to rebalance. Start with your Safe holding the sell token and your total amount decided; test a part size in a swap quote, set the count and interval, then review the schedule and sign. The order list confirms the task is done when it shows your chosen count and schedule.

How do you choose the part count and interval?

Part count sets the amount sold each time: divide the total by the number of parts. A smaller part can reduce price impact because it asks less of the pool in one trade. But each part settles as its own order and has its own network cost, so doubling the count also roughly doubles the number of charges.

Begin with a quote for one part’s size and look at its estimated price impact. Aim for under about 0.5% per part as a working target, then divide your total by the largest part size that meets it and round up. The result is a starting count, not a guarantee: pool depth and the quote can change, so check the resulting per-part amount again before signing.

Take a sizable token sale and test a candidate part amount in the swap quote. If that amount pushes estimated impact above the target, reduce the part size and increase the count until the quote is below it. The cowswap limit orders topic adds useful background on setting order price limits; cowswap TWAP price protection is a separate guardrail for an unfavorable price move, not a substitute for sizing each part.

Set the interval to give arbitrage time to restore the pool price between executions. Several minutes or more is a reasonable starting point for a thin token, but the needed time depends on how quickly that pool’s price recovers. A shorter gap can send the next part into a pool that has not yet rebalanced; a longer gap spreads the sale further across time.

Then weigh that recovery time against cost and market exposure. On Ethereum mainnet, many small parts can cost more in repeated network charges than they save in price impact. Total network cost is approximately the part count multiplied by the cost per part. Total duration is parts multiplied by interval, so increasing either can lengthen the run and leave more time for market moves to affect execution.

How do you enter and confirm the schedule?

In cowswap, a TWAP order runs through a Safe using CoW Protocol’s ComposableCoW framework. The Safe holds and signs the conditional order; each scheduled part is handled as its own order. With the Safe connected and the TWAP tab open, use this sequence:

  1. Enter the total sell amount. The form should show the token and amount you intend to sell.
  2. Test one candidate part size in a swap quote. The quote shows the estimated price impact for that amount.
  3. Set the number of parts from the quote result, rounding up from total amount divided by the acceptable part size. The form shows the per-part amount.
  4. Set the part duration or interval long enough for the pool to rebalance. The form shows the resulting schedule and total duration.
  5. Set price protection to define the unfavorable price movement you are willing to tolerate. The setting appears with the order parameters for review.
  6. Review the per-part amount and total duration, then sign with the Safe. The TWAP order appears in the order list with the chosen part count and schedule; that confirms setup is complete.

Related

What price protection should a TWAP order use?

Price protection should match how far the sale price may move unfavorably before a part should stop. Choose a tolerance you can accept for the order, then review it alongside part size: protection controls the execution boundary, while part size is what you tested for price impact.

Can a running TWAP order be cancelled?

A running TWAP can be cancelled from the orders overview. Review the active order there and use its available cancel action; the schedule shown in the order list lets you identify the order you are changing.
