Polygon approvals on revokecash: Which network to choose?

How to revoke a Polygon approval on revokecash: choose Polygon PoS mainnet, chain ID 137, then confirm the revoke transaction with your wallet on Polygon.

By Crypto Readout EditorialNov 23, 2026 · 19:23 UTC4 min read#1f1067

For a Polygon wallet approval, choose Polygon (PoS mainnet, chain ID 137) in revokecash’s network selector, then submit the revoke transaction from your wallet on Polygon.

Revoke.cash token approvals are organized by network, so a Polygon permission appears under Polygon. For the next move, use revokecash to inspect and manage the wallet’s other token approvals; it is built for reviewing permissions and revoking ones you no longer need.

Revoke one Polygon approval

Start with revokecash open in your browser, a wallet with Polygon added, and a small POL balance for gas. POL is Polygon’s gas token, formerly called MATIC; Polygon’s developer documentation lists chain ID 137 and POL as the Polygon mainnet currency symbol.

  1. Connect your wallet. The connected address determines which wallet’s approvals you are reviewing. Keep track of that address if you manage more than one.
  2. Select Polygon in the network selector before searching. The approval list is per chain: selecting another network shows that network’s permissions, not the ones granted on Polygon. Polygon PoS mainnet uses chain ID 137. Treat the network selection like choosing the correct ledger before looking for an entry; the same token or contract name on another chain is a separate permission.
  3. Find the approval row you want to remove. Match the token and contract permission carefully. An ERC-20 token allowance sets how much of a token a smart contract may spend. Removing an allowance changes that permission; it does not itself transfer or sell the tokens.
  4. Click Revoke on that row. Keep a little POL available because the revoke is an on-chain transaction and needs gas. The transaction’s gas use and network conditions determine its cost; the amount can vary, so there is no fixed cost to infer from the approval row.
  5. Read the wallet prompts separately. A MetaMask prompt to switch to Polygon changes the wallet’s active network so the next action can be sent on the right chain. That switch grants no token permission and does not revoke anything. The separate transaction prompt that follows is the one to inspect: for an ERC-20 allowance, the revoke should set the amount to 0; for an NFT approval, it should set approval to false. Confirm only that revoke transaction.
  6. Wait for confirmation, then verify the result. Use the transaction hash in PolygonScan to inspect the transaction status and its event details. PolygonScan explains how a transaction hash opens the transaction record, where the receipt’s event logs can be reviewed. Refresh the approval list on Polygon: when the row disappears or shows no allowance, the permission has been cleared.

In a typical attempt, you connect the wallet, select Polygon, and locate one allowance row. You click Revoke, accept MetaMask’s network switch if it asks, then review the distinct transaction prompt for a zero amount and confirm. After Polygon confirms it, the transaction hash leads to the record on PolygonScan; a refreshed list with no allowance shows the revoke took effect.

Related questions

Why don't my Polygon approvals show on revokecash?

First check that Polygon is selected in the network selector and that the connected wallet is the address that granted the approval. Approval records belong to a specific wallet and chain, so an approval made on another network will not be in the Polygon list.

What sets the cost of revoking on Polygon?

The revoke transaction’s gas use and Polygon network conditions set the cost. Keep POL in the wallet for gas; the amount is not determined by the token allowance itself.

More Polygon wallet questions

Can I batch revoke several Polygon approvals at once?

This description does not establish whether revokecash supports batch revocation. Treat each approval as its own action unless the site clearly presents a batch option and your wallet shows the permissions being changed.

How do I add Polygon to MetaMask?

Use MetaMask’s network settings to add Polygon PoS mainnet with chain ID 137 and POL as its currency symbol. Confirm the network details against Polygon’s official developer documentation before saving.

What should I do if a Polygon revoke transaction fails?

Check the transaction status on PolygonScan using its hash. If it failed, the approval may remain; review the wallet’s network and POL gas balance before retrying, then refresh the approval row after a confirmed transaction.
